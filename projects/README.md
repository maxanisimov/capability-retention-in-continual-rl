# Projects

Project-specific experiment code lives here. Shared, reusable functionality belongs in `core/`; tutorial material belongs in `tutorials/`.

- `safe_crl/` contains safe continual RL pipelines, utilities, notebooks, and artifacts.
- [`safe_policy_optimisation/`](safe_policy_optimisation/README.md) contains the PSPO paper experiments, safe-RL baselines, and reproducible analysis scripts.
